# Data and input preparation

The notebook uses sklearn.datasets.load_digits (1,797 samples). See DATA.md for the underlying UCI dataset attribution.

Alpaydin, E. & Kaynak, C. (1998). Optical Recognition of Handwritten Digits. UCI Machine Learning Repository. https://doi.org/10.24432/C50P49. CC BY 4.0: https://creativecommons.org/licenses/by/4.0/. The sklearn loader provides the 8×8 image subset; pixel values are normalized by 16.
